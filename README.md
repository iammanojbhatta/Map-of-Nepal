# 🗺️ Map of Nepal — Interactive Province & District Map

An **interactive map of Nepal** built with Leaflet.js and GeoJSON data: explore all **7 provinces** and their districts right in the browser.

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-0D1117?style=for-the-badge&logo=javascript&logoColor=F7DF1E)
![Leaflet](https://img.shields.io/badge/Leaflet-Maps-0D1117?style=for-the-badge&logo=leaflet&logoColor=199900)

## Open it
Open `index.html` in a browser (internet needed for the Leaflet library and map tiles).

## Files
- `index.html` — the map page
- `nepal-province.js` — province boundaries data
- `province1-district.js` … `province7-district.js` — district data for every province
- `map of Nepal.jpg` — reference image

Great for students, teachers and anyone who loves Nepal's geography. 🇳🇵
